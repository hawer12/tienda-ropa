#  Tienda de Ropa 

Tienda en línea desarrollada para un negocio real de ropa.

## Tecnologías utilizada

- HTML5
- CSS3
- JavaScript (ES6+)
- Node.js
- MongoDB

##  Funcionalidades

- Catálogo de productos
- Carrito de compras
- Gestión de pedidos
- Panel de administración de inventario

##  Cómo ejecutar el proyecto

1. Clona el repositorio
   git clone https://github.com/hawer12/tienda-ropa

2. Instala las dependencias
   npm install

3. Crea un archivo .env con tus credenciales
   MONGODB_URI=tu_uri_aqui
   PORT=3000

4. Inicia el servidor
   node index.js
